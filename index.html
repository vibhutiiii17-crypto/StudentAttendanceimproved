⚡ Why Vanilla JS is Different from React

  • The right panel only updates after you click Submit — not while typing.
  • We manually call getElementById() and set .textContent to update the DOM.
  • All state (name, reg, course) is read directly from the DOM on submit — there is no shared state object.
  • Showing/hiding sections is done by toggling CSS classes (hidden) via JavaScript.
  • In React, all of this is handled automatically by useState() and re-rendering.
